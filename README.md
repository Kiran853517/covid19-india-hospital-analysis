# COVID-19 India Hospital and Bed Availability Visualization

This project fetches live hospital and bed data from the [Rootnet COVID-19 API](https://api.rootnet.in/covid19-in/hospitals/beds), processes it using **Pandas**, and visualizes the number of **urban hospitals across Indian states** using **Matplotlib**.

## Features
- Fetches real-time data from the Rootnet API.
- Parses JSON data into a Pandas DataFrame.
- Visualizes state-wise hospital statistics.
- Simple and reusable code.
